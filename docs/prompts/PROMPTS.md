# PoPo 사이트 개선 — Claude Code 단계별 프롬프트

기존 Manus 코드가 들어 있는 VS Code 프로젝트에서 Claude Code 패널을 열고, 아래 프롬프트를 **0단계부터 하나씩** 붙여 넣는다.
각 단계가 끝나면 결과를 확인(필요하면 `npm run dev` 등으로 화면 확인)한 뒤 다음 단계로 넘어간다.
0단계는 플랜 모드로 실행하는 것을 권장한다 (코드를 바꾸지 않고 분석만).

---

## 0단계 — 코드 분석 (수정 금지)

```
이 프로젝트는 Manus로 만든 PoPo애견미용실 홈페이지야. CLAUDE.md와 docs/business-facts.md를 먼저 읽어.

지금은 코드를 수정하지 말고 분석만 해줘.

1. package.json, lock 파일, 설정 파일, 폴더 구조를 보고 스택을 파악해: 프레임워크, 빌드 도구, 스타일 방식, 라우팅, 서버/API 유무, 패키지 매니저, 실행·빌드·린트 명령어.
2. 페이지를 구성하는 섹션 컴포넌트를 순서대로 나열하고, 각 섹션의 파일 경로를 적어줘.
3. 매장 정보(주소·전화·영업시간·가격·이벤트)가 하드코딩된 위치와, 데이터 파일로 분리된 위치를 구분해줘.
4. 예약 폼과 후기 기능이 어떻게 구현돼 있는지(localStorage 사용 여부, 서버 전송 여부) 확인해줘.
5. <head> 메타 태그(title, description, OG, canonical)가 어디서 정의되는지, SPA라서 초기 HTML에 안 들어가는 문제가 있는지 확인해줘.
6. 빌드 명령을 한 번 실행해서 현재 통과하는지 알려줘.

분석이 끝나면 CLAUDE.md의 "2. 코드 환경" 섹션에 있는 TODO를 확인한 실제 값으로 채워줘. 이 파일 수정만 허용해.
```

## 1단계 — 매장 정보를 실제 영업 정보로 교체

```
/popo-toolkit:update-info

추가 요구사항:
- "오픈 준비 중", "위치할 예정", "추후 업데이트"로 비어 있던 영업시간·전화·주차·위치 섹션을 business-facts.md의 확정 값으로 채워줘.
- 지번 주소(관양동 1455-11)는 미확인이므로 도로명 주소만 써줘.
- 예약 섹션의 모의 폼은 삭제하고, 전화·카카오톡 채널·인스타그램 버튼으로 바꿔줘. "100% 예약제" 문구를 함께 넣어줘.
- 오픈 이벤트(~2026-12-30, 버블 스파·탄산 스파·머드팩 중 1가지 선택) 배너를 첫 화면 근처에 추가해줘.
- 서비스 목록에 스파 메뉴 3가지를 추가해줘. 가격은 아직 없으니 "상담 후 안내"로.
- 모바일에서 하단 고정 바(전화 / 카카오톡 문의)를 추가해줘.
끝나면 빌드하고, 바꾼 내용과 아직 비어 있는 정보를 표로 보고해줘.
```

## 2단계 — 고객 노출 문구 정리

```
/popo-toolkit:copy-check

추가 요구사항:
- 후기 작성 기능(브라우저에만 저장)은 통째로 제거하고, 그 자리에 "네이버 리뷰 보기" 링크 자리만 남겨줘. 네이버 플레이스 URL은 business-facts.md에 TODO이므로 지금은 버튼을 숨기고 주석으로 표시해줘.
- 가격 섹션의 "가격표 준비 중" 안내는 "견종·체중·모량에 따라 상담 후 안내드립니다" 한 문장으로 줄여줘.
- FAQ의 예약 관련 답변을 실제 예약 방법(전화·카카오톡, 100% 예약제)으로 바꿔줘.
- 취소 규정 FAQ는 내가 확정하지 않았으니 삭제하고, 삭제했다고 보고해줘.
```

## 3단계 — 브랜드 디자인 맞추기

```
/popo-toolkit:brand-guide 를 기준으로 디자인을 실제 로고 톤에 맞춰줘.

1. 먼저 지금 쓰고 있는 색상(녹색 #26352C 계열 포함)이 정의된 곳을 찾아 표로 보여주고, brand-guide의 토큰으로 어떻게 바꿀지 계획을 말해줘. 내가 확인하면 진행해.
2. 색상은 CSS 변수(또는 Tailwind 테마)로 한 곳에 모아서 정의해줘.
3. 기존 히어로 일러스트(popo-hero.svg)는 실제 로고로 교체할 자리만 만들어줘. 로고 원본 파일 경로는 내가 넣을게: public/brand/popo-logo.png (없으면 TODO로 표시하고 기존 이미지는 유지).
4. 섹션을 7~8개로 통합해줘. 소개·차별화·POPO CARE·케어 기록·케어 저니처럼 겹치는 섹션은 하나로 합치고, 합친 결과 구성을 먼저 보여줘.
5. 내비게이션 메뉴가 두 번 중복 렌더링되는 문제가 있으면 고쳐줘.
6. theme-color 메타도 새 배경색으로 바꿔줘.
7. 본문 텍스트 대비가 4.5:1 이상인지 계산해서 확인해줘.
```

## 4단계 — SEO 정리

```
/popo-toolkit:seo-audit

특히 다음을 확인해줘:
- og:image가 상대경로(/popo-logo.png)로 되어 있으면 절대 URL로 바꿔줘.
- title과 description에 "포포(PoPo)"와 "안양 관양동 애견미용"을 함께 넣어줘.
- LocalBusiness 구조화 데이터를 확정 정보만으로 추가해줘.
- naver-site-verification 메타는 값이 없으니 자리만 주석으로 남겨줘.
점검표 결과와, 내가 직접 해야 할 일(도메인, 네이버 서치어드바이저 등록 등)을 정리해줘.
```
