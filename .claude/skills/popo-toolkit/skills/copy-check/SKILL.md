# 고객 노출 문구 점검

## 1. 검사
화면에 렌더링되는 텍스트만 대상으로, 아래 패턴을 검색한다. 주석과 코드 식별자는 제외한다(HTML 주석 안의 TODO는 노출되지 않으므로 허용).
검사 대상:
- `index.html` 본문과 `<head>`(title·description·OG도 고객이 보는 문구다)
- `public/` 안의 SVG 이미지 속 `<text>` 요소 — 2026-10-17 히어로 SVG에 "POPO QUIET CARE" 글자가 남아 있다가 검토에서 걸렸다
- 공유 이미지(`public/og-image.jpg`)처럼 글자가 그려진 이미지는 열어서 눈으로 확인
- CSS `text-transform: uppercase`가 상호를 대문자로 바꾸지 않는지

| 분류 | 패턴 | 처리 |
|---|---|---|
| 준비 중 | `오픈 준비`, `준비 중`, `위치할 예정`, `추후 업데이트`, `추후 공개`, `정식 오픈` | 실제 정보로 교체하거나 문장 삭제 |
| 모의 기능 | `모의 입력`, `전송·저장되지 않`, `이 브라우저에만`, `localStorage` | 기능 자체 제거 → 연락 버튼/네이버 리뷰 링크로 대체 |
| AI 지시문 | `임의 생성하지 않았`, `첨단 디지털 시스템`, `가짜 Before/After`, `허위 사례`, `과장된` | 문장 삭제 |
| 상호 표기 | `POPO` (대문자만) | `PoPo`로 교체. 단 URL·계정명·코드 식별자는 유지 |
| 과도한 부호 | `«` `»` | 섹션당 1회 이하로 줄이고 나머지는 일반 문장으로 |
| 날짜 모순 | 정책 "확정 안내"인데 다른 곳은 "미확정" | 한쪽으로 통일, 근거 없으면 삭제 |

## 2. 판단 기준
- 고객이 읽었을 때 "아직 영업 안 하나?" 또는 "누가 AI에게 시킨 문장인가?"로 느껴지면 고친다.
- 정직함 자체는 유지한다. "실제 고객 동의를 받은 사진만 올립니다" 같은 한 문장은 남겨도 된다. 반복·과잉 해명만 줄인다.
