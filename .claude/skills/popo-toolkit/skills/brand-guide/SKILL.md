# PoPo 브랜드 가이드

## 방향
실제 로고(크림색 비숑 일러스트 + 브라운 "PoPo" 레터링)와 인스타·카카오 채널의 따뜻한 베이지 톤에 사이트를 맞춘다.
녹색 계열(`#26352C`, `#4F614C`, `#71806A` 등 Manus 시절 색)은 쓰지 않는다. 이미지·SVG 안의 색도 마찬가지다.

## 컬러 토큰 (2026-10-17 적용됨)
정의 위치: `src/style.css`의 `:root` **한 곳뿐**. CSS 규칙과 HTML에는 hex를 직접 쓰지 않고 토큰(`var(--…)`)만 쓴다.
값은 인스타그램 캡처에서 샘플링한 초안이다. 원본 로고 파일이 들어오면 그 파일에서 다시 추출해 갱신한다.

| 토큰 | 값 | 용도 | 대비 |
|---|---|---|---|
| `--popo-cream` | `#FFFCF5` | 페이지 배경, `theme-color` | — |
| `--popo-sand` | `#F6E5D3` | 교차 섹션 배경, 스파 카드, 이벤트 배너 | — |
| `--popo-beige` | `#E2CDBA` | 구분선·테두리 | 장식용 |
| `--popo-brown` | `#725E46` | 보조 텍스트, 라벨, 아이콘 | cream 6.02 / sand 5.01 / 흰색 6.17 |
| `--popo-brown-deep` | `#4A3A2A` (**임시값**, 로고 레터링 색으로 교체 예정) | 본문·제목·주요 버튼·푸터 배경 | cream 10.62 / sand 8.84 |
| `--popo-brown-darker` | `#3B2E22` | 주요 버튼 hover | 흰 글자 13.13 |
| `--popo-kakao` / `--popo-kakao-text` | `#FEE500` / `#191919` | 카카오톡 버튼에만 사용 | 13.75 |

- 그 위에 용도별 토큰(`--color-bg`, `--color-text`, `--color-text-muted` 등)이 있다. 새 스타일은 용도별 토큰을 우선 쓴다.
- 텍스트 색·배경 조합은 WCAG AA(4.5:1) 이상이어야 한다. 새 조합을 만들면 **계산해서** 확인한다. `#8A7560`처럼 cream 위 4.27인 색은 텍스트에 쓰지 않는다.
- 다크모드는 필수 아님. 넣는다면 배경 짙은 브라운, 텍스트 크림.

## 타이포
- 본문·제목 모두 **Pretendard**(CDN `@v1.3.9` 고정). 사용자 결정(2026-10-17)으로 별도 제목 웹폰트는 쓰지 않는다. 바꾸려면 사용자에게 확인.
- 이미지를 만들 때(공유 이미지 등) Pretendard가 로컬에 없으면 Noto Sans KR을 쓴다.
- 모바일 본문 16px 이상.

## 로고
- 원본 로고 파일은 아직 없다(`public/brand/popo-logo.png` 자리 예정). 그 전까지 헤더·푸터는 **텍스트 로고**("PoPo 애견미용실")를 쓴다.
- `index.html`의 `TODO(로고)` 주석 4곳(헤더, 히어로 이미지, 푸터, 파비콘)이 로고를 넣을 자리다. 로고가 오면 이 자리를 채우고 `--popo-brown-deep`을 재추출하고 `public/og-image.jpg`도 로고로 다시 만든다.

## 이미지
- 로고는 원본 파일만 사용. 다시 그리거나 비슷하게 만들지 않는다.
- 히어로의 `public/assets/popo-hero.svg`는 Manus가 그린 임시 일러스트를 브라운으로 바꾼 것이다. 로고·매장 사진이 오면 교체한다.
- 이미지·SVG 안에 글자를 넣었다면 그 글자도 상호 표기·금지 문구 규칙을 따른다(`<text>` 요소까지 확인).
- 실제 매장 사진(리셉션, 원목 욕조)을 히어로·소개에 우선 사용. 원본이 없으면 자리만 만들고 TODO로 표시.
- 반려견 사진은 보호자 동의를 받은 실제 사진만. 스톡 사진으로 "우리 고객"처럼 보이게 하지 않는다.
- 모든 이미지에 의미 있는 alt.

## 톤
- 따뜻하고 차분하게, 짧게. "안심", "편안함", "1:1 맞춤", "100% 예약제"가 핵심어.
- 같은 메시지를 섹션마다 반복하지 않는다.

## 레이아웃
- 모바일 우선. 첫 화면에 상호, 한 줄 소개, 전화·카톡 버튼, 오픈 이벤트가 보여야 한다.
- 모바일 하단 고정 바: 전화 / 카카오톡 문의.
- 섹션 수는 7~8개 이내. 현재 7개: 히어로(`#home`) → 소개(`#about`) → 서비스·가격(`#services`) → 첫 방문(`#first-visit`) → FAQ(`#faq`) → 오시는 길(`#location`) → 예약 안내(`#reservation`). 네이버 리뷰 섹션은 주석으로 숨겨져 있다.
- 메뉴는 한 벌(`#siteNav`)만 둔다. 데스크톱은 가로, 모바일은 햄버거 드로어. 메뉴를 두 벌로 만들지 않는다.
- 겹화살괄호 «» 인용은 섹션당 1회 이하.
