# PoPo 브랜드 가이드

## 방향
실제 로고(크림색 비숑 일러스트 + 브라운 "PoPo" 레터링)와 인스타·카카오 채널의 따뜻한 베이지 톤에 사이트를 맞춘다.
기존 Manus 사이트의 짙은 녹색(`#26352C`) 계열과 별도 히어로 일러스트는 채널과 톤이 달라 교체 대상이다.

## 컬러 토큰 (초안)
아래 값은 인스타그램 화면 캡처에서 샘플링한 것이다. 원본 로고 파일이 들어오면 그 파일에서 다시 추출해 갱신한다.

| 토큰 | 값 | 용도 |
|---|---|---|
| `--popo-cream` | `#FFFCF5` | 페이지 배경 |
| `--popo-sand` | `#F6E5D3` | 섹션 배경, 카드 |
| `--popo-beige` | `#E2CDBA` | 구분선, 보조 배경 |
| `--popo-brown` | `#725E46` | 본문 강조, 아이콘 |
| `--popo-brown-deep` | TODO (로고 레터링 원본 색) | 제목, 주요 버튼 |
| `--popo-kakao` | `#FEE500` | 카카오톡 버튼에만 사용 |

- 본문 텍스트는 크림 배경 위에서 WCAG AA 대비(4.5:1)를 넘겨야 한다. `--popo-brown`이 부족하면 더 진한 브라운을 텍스트 전용으로 정한다. 대비는 계산해서 확인한다.
- 다크모드는 필수 아님. 넣는다면 배경 짙은 브라운, 텍스트 크림.
- `theme-color` 메타도 새 배경색으로 바꾼다.

## 타이포
- 한글 본문: 가독성 높은 산세리프(Pretendard 또는 Noto Sans KR). 이미 프로젝트에 있는 폰트가 있으면 그것을 우선.
- 제목: 둥글고 부드러운 느낌이 로고와 어울린다. 새 웹폰트 추가 전 사용자에게 확인.
- 모바일 본문 16px 이상.

## 이미지
- 로고는 원본 파일만 사용. 다시 그리거나 비슷하게 만들지 않는다.
- 실제 매장 사진(리셉션, 원목 욕조)을 히어로·소개에 우선 사용. 원본이 없으면 자리만 만들고 TODO로 표시.
- 반려견 사진은 보호자 동의를 받은 실제 사진만. 스톡 사진으로 "우리 고객"처럼 보이게 하지 않는다.
- 모든 이미지에 의미 있는 alt.

## 톤
- 따뜻하고 차분하게, 짧게. "안심", "편안함", "1:1 맞춤", "100% 예약제"가 핵심어.
- 같은 메시지를 섹션마다 반복하지 않는다.

## 레이아웃
- 모바일 우선. 첫 화면에 상호, 한 줄 소개, 전화·카톡 버튼, 오픈 이벤트가 보여야 한다.
- 모바일 하단 고정 바: 전화 / 카카오톡 문의.
- 섹션 수는 7~8개 이내: 히어로 → 소개(차별점) → 서비스·스파 → 첫 방문 안내 → FAQ → 오시는 길·영업시간 → 연락.
